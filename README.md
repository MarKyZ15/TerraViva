# TerraViva

**Tecnologia a serviço da terra.**

## Sobre o projeto

O **TerraViva** é um projeto de tecnologia sustentável voltado ao monitoramento das condições do solo por meio de sensores e de um sistema digital para visualização e acompanhamento de dados.

A proposta consiste em integrar um protótipo físico a um dashboard interativo, permitindo visualizar informações relacionadas ao ambiente de cultivo. A solução busca facilitar a interpretação dos dados e apoiar decisões mais conscientes sobre o manejo do solo e o uso dos recursos naturais.

O projeto une tecnologia, inovação e sustentabilidade, com foco no desenvolvimento de uma solução digital que possa evoluir futuramente para o monitoramento por meio de sensores físicos.

## Objetivo

Desenvolver uma solução tecnológica que contribua para o monitoramento das condições do solo, integrando uma interface digital de visualização de dados a uma proposta de instrumentação física, com foco na sustentabilidade e no uso responsável dos recursos naturais.

## Tecnologias utilizadas

- **HTML5:** estruturação da interface.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** lógica de funcionamento, interatividade e atualização da interface.
- **Chart.js:** criação e atualização de gráficos para visualização dos dados.

## Funcionalidades implementadas

- Dashboard para visualização das informações de monitoramento.
- Gráficos interativos com dados demonstrativos.
- Indicadores visuais para acompanhamento das variáveis apresentadas.
- Interface com recursos de interação e visualização dinâmica.
- Estrutura preparada para futuras evoluções e integração com sensores físicos.

## Como executar o projeto

### Pré-requisitos

- Navegador atualizado, como Google Chrome, Microsoft Edge ou Mozilla Firefox.
- Conexão com a internet para carregar as bibliotecas externas utilizadas pelo dashboard.

### Execução local

1. Clone o repositório ou faça o download dos arquivos do projeto.
2. Extraia os arquivos, caso tenha realizado o download em formato ZIP.
3. Abra a pasta do projeto.
4. Abra o arquivo `index.html` em um navegador.

**Repositório:** [TerraViva no GitHub](https://github.com/MarKyZ15/TerraViva)
