SOBRE O TERRAVIVA

Tecnologia acessível para decisões melhores.

O TerraViva é um projeto acadêmico que explora uma interface simples para visualizar indicadores ambientais do solo. Nesta versão, os dados são simulados; o monitoramento real dependerá da integração futura com sensores e uma fonte de dados confiável.
